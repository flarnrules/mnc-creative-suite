06 / Motion tracks

Program precise journeys through your fractal. Choose boomerang, forward repeat, or a smooth return for each track. Integer repeats keep all tracks on one shared loop.

Uses whole cycles for a seamless phase wrap. An enabled Band phase track takes control. Recorded takes keep their captured phase.

Start and active-time are in seconds. Repeats fit inside active-time; outside it the track rests at its start value. Add waypoints for multi-stage motion. Cyclic forward tracks can extend past slider bounds to complete full turns. Hue repeats every 1, band phase every π/4, and angles every 360°. Zoom and magnification need a return path; a forward reset can jump. Smooth return closes the path without replaying all its waypoints backward.
